# Good Vibes Roofing 🏠⚡

> **Manufacturer-Certified Roofing Contractor in Houston, Texas**  
> Certified Installers for **GAF**, **TAMKO**, **Attic Breeze**, and **BBB Accredited (A+)**.

A state-of-the-art, high-performance website for **Good Vibes Roofing**, featuring cinematic video hero effects, interactive appointment scheduling, Google reviews carousel, Hearth financing calculator, GAF Learning Center, and an automated booking system.

---

## 🌟 Key Features

- **Cinematic Video Hero**: Looping background drone video, frosted glass floating pill navbar, logo reveal, and dripping scroll indicator.
- **Automated Booking Appointment System**: Interactive appointment scheduler allowing homeowners to pick an inspection date (next 14 days), choose available time slots (morning, afternoon, evening), submit property details, and receive an instant booking confirmation.
- **4-Step Free Assessment Flow**: Step-by-step interactive questionnaire with auto-advance and direct click-to-call action.
- **Google Reviews & Testimonials Carousel**: 5.0 Star verified badge with official Google branding, smooth scrolling carousel with navigation arrows, real customer feedback, and service tags.
- **Interactive Process Timeline**: Scroll-linked vertical timeline featuring a dynamic glowing progress fill, moving star indicator, step numbers that illuminate on scroll, and synchronized image crossfades.
- **Meet Jordan (Owner Section)**: Custom video player facade for Jordan's personal message, personal quotes, checklist, and Instagram connect card.
- **Recent Work Project Gallery & Lightbox**: Customer project cards across Houston, Missouri City, and Pearland with photo counters and a fullscreen lightbox gallery.
- **GAF Learning Center**: Interactive tab switcher comparing warranty tiers (System Plus vs. Golden Pledge), shingle specifications (Timberline HDZ®), and roof system anatomy.
- **Flexible Financing Calculator (Hearth)**: Real-time loan payment estimator with loan amount slider ($4k–$35k) and term selector (12-mo 0% APR promo, 36-mo, 60-mo, 120-mo).
- **Live Chatbot Assistant**: Floating launcher with unread notification badge, intelligent keyword routing, quick prompt chips, and automated booking trigger.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic, accessible markup with OpenGraph tags and Schema.org `RoofingContractor` JSON-LD structured data.
- **CSS3**: Custom design system using CSS custom properties (variables), glassmorphism (`backdrop-filter`), responsive CSS grids, and GPU-accelerated keyframe animations.
- **Vanilla JavaScript**: Lightweight, modular interactivity with no heavy external framework dependencies.
- **Google Fonts**: Editorial typography using *Fraunces* serif and *Inter* sans-serif.

## 🚀 Local Development

To run the site locally:

```bash
# Clone the repository
git clone https://github.com/ShinjiniMondal/good-vibes-roofing.git

# Navigate into the project directory
cd good-vibes-roofing

# Start a local web server (Python 3)
python -m http.server 8080
```

Open your browser and navigate to `http://localhost:8080`.
